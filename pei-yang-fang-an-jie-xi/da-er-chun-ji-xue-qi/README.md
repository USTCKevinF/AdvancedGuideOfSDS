# 大二春季学期

从本学期开始，同学们将会在课程中逐步接触更多**实践**相关的内容——

* **深度学习基础**作为AIDS的核心专业课之一，正式带领同学们步入了当今主流的人工智能方向——深度学习
* **数据分析与实践**作为DS的必修课程，更是从零开始大幅拔高了同学们利用python进行数据分析处理的能力
* **数据库系统概论**十分具有大数据特色，与业界结合紧密，课程涉及了sql语言和前后端开发能力
