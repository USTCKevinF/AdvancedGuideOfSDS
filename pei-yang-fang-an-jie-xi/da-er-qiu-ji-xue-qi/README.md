# 大二秋季学期

从这个学期开始，同学们可以说正式踏入了 人工智能与数据科学领域 的门槛——

* **人工智能与机器学习基础**作为本专业的第一门专业课程，可能在难度与深度上有极大的提升，同时也会带来极大的收获
* **概率论与数理统计**的知识在机器学习和深度学习相关课程中应用极为广泛，也是随机过程的前置科目
* **数据结构**更是在编程的世界当中起到了根基的作用，同时也是考研408的科目之一
* **计算系统概论**虽不如计算机组成原理深入，但是可以作为计算机的硬件原理通识课打开计算机底层运行逻辑的大门，对之后理解操作系统等计算机专业课知识、从事软硬件相关开发工作有着不可忽视的作用
* **复变函数**作为数学分析的延申与扩展，为之后的随机过程、信号与系统等课程中打下了基础

从本学期开始，课程的容量与难度跨入了一个新的等级，请同学们做好一定的心理准备。同时，指定合理的学习规划、养成良好的学习习惯、以及在课业与竞赛、科研、娱乐达到平衡，能帮助你较好的度过这一时期。

迎接挑战吧！祝愿同学们全都收获满满：）
